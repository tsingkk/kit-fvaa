# Kit 文件版本存档助手 (Kit File Version and Archive Assistant)

**Kit 文件存档助手** 是一个基于 Python 开发的轻量级、图形化本地文件版本管理工具。它可以帮助用户针对本地目录进行一键存档、版本控制、修改监视和历史回溯。非常适合非程序员、写作者、设计师、美术工作者以及需要频繁修改文件的独立开发者使用。

## ✨ 主要功能

- **📦 一键存档**: 快速将工作目录中的当前状态保存为一个版本，自动排除临时文件和无用目录（如 `.git`, `node_modules`, `__pycache__` 等）。
- **🕒 版本历史与日志**: 
  - 自动编制递增的版本号。
  - 支持为版本添加 **Markdown格式** 的修改说明和自定义标签。
  - 清晰显示每次存档的时间和备注，随时查看历史操作记录。
- **⏪ 文件回溯**: 轻松选中历史版本，一键安全恢复，将工作目录还原到指定状态。
- **👀 状态监视**: 在图形界面中高亮显示工作目录各文件的实时状态（**新增**、**修改**、**删除**、**不变**）。支持手动刷新和后台自动监视。
- **💾 极致的空间优化**: 使用 **硬链接 (Hard Links)** 技术处理不同版本中未发生改变的文件。无论你存了多少个版本，只要文件没变，就不会造成额外的硬盘空间开销。
- **📁 格式通用**: 适用于绝大多数文件类型，无论是文本代码还是图片、音频等二进制文件，均可完美存档。
- **🎨 现代图形界面**: 采用简约的暗黑风格界面 (Cyborg 主题)，定制滚动条和高亮提示，对比度适宜，操作直观。

## 🛠️ 技术栈

- **语言**: Python 3.x
- **GUI 框架**: `tkinter`, `ttkbootstrap`
- **文本渲染**: `markdown`, `tkhtmlview`
- **核心逻辑**: `hashlib` (MD5比对), `os.link` (硬链接优化)

## 🚀 安装与运行

1. **克隆本仓库或下载源码**:
   ```bash
   git clone https://github.com/yourusername/kit-fvaa.git
   cd kit-fvaa
   ```

2. **安装必要的 Python 依赖库**:
   建议在虚拟环境中运行，执行以下命令安装依赖：
   ```bash
   pip install ttkbootstrap markdown tkhtmlview
   ```

3. **运行程序**:
   ```bash
   python main.py
   ```

## 📖 使用指南

1. **选择工作目录**: 打开软件后，首先点击“选择目录”按钮，指定你需要进行版本管理的本地文件夹。
2. **状态刷新与监视**: 
   - 点击“刷新状态”可手动比对并查看当前目录下文件的变动情况。
   - 点击“开始监视”将会开启后台线程，自动刷新并显示文件状态。
3. **编辑说明与存档**: 
   - 点击“编辑存档说明”，可以使用 Markdown 编写本次存档的详细日志。
   - 点击“一键存档”生成新版本，存档文件会安全地存放在工作目录下的 `.vcs` 隐藏文件夹中。
4. **版本管理与回溯**:
   - 在右侧“版本历史”面板中，可以查看所有的存档版本。
   - 在标签输入框填入文本并点击“添加标签”，可为选中的重要版本打上标记（如 `Release v1.0`）。
   - **查看说明**: 点击版本列表中的“说明”列，可弹窗查看渲染后的 Markdown 文档。
   - **恢复版本**: 若要撤销当前的灾难性更改，选中需要恢复的历史版本，点击“恢复版本”即可覆盖当前工作区。

## 🧠 工作原理与文件结构

- **差异比对**: 核心类 `VersionControl` 会遍历目录并计算文件的 MD5 哈希值，结合文件修改时间精准判断文件变更状态。
- **本地存储机制**: 所有的版本数据全部集中保存在工作目录下的 `.vcs/` 隐藏文件夹中，按需生成，不会污染系统的其他地方。
  - `.vcs/versions/`: 按版本号（1, 2, 3...）分别存储文件的副本。
  - `.vcs/manifest.json`: 存储版本元数据、标签映射表以及操作历史日志。
  - `.vcs/cache.json`: 当前工作区文件的状态缓存，用于快速对比。
- **硬链接优化策略**: 每次新建存档时，如果文件与上一个版本相比 MD5 相同（即未发生变化），系统会使用操作系统底层的 `os.link` 为文件创建硬链接，直接指向上一版本的文件位置。这避免了重复拷贝，极大提高了运行效率并节约了磁盘空间。
